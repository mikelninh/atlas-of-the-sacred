# Image credits and visual labels

The public experience uses archaeological and heritage-site photographs hosted by Wikimedia Commons. Every image is labelled as photography rather than reconstruction or evidence for an interpretive claim. Copyright and licence details remain authoritative on each linked Commons file page.

## Editorial rule

Every visual must be labelled as one of:

1. archaeological photograph;
2. documented reconstruction;
3. interpretive reconstruction;
4. diagram;
5. cinematic visualisation.

Photography illustrates a place; it does not itself establish the historical claims displayed beside it.
